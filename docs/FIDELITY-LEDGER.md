# 视觉保真记录

> 历史归档：本文对应 Tideguard v0.2–v0.3。墨衡 v0.4 的视觉真值、浏览器截图、响应式检查和修复迭代见项目根目录 `design-qa.md`。

对照对象：`tideguard-concept.png`；最终实现：`tideguard-desktop.png` 与 `tideguard-mobile.png`。

| 对照点 | 概念稿意图 | 最终实现证据 | 处理结果 |
|---|---|---|---|
| 应用外壳 | 左侧窄导航、顶部安全条、中央主区、右侧检查器 | 桌面截图保持四区结构，1415px 文档宽度下 `scrollWidth = clientWidth` | 保留层级与密度，未引入装饰性大标题 |
| 模拟盘边界 | `OKX 模拟盘` 与观察/演练状态持续可见 | 桌面和 375×812 验收中首屏均可见；页脚重复展示 `x-simulated-trading: 1` | 完整保留，并使用文字而非仅靠颜色 |
| 行情主视觉 | 低装饰折线、弱网格、来源和时间证据 | 最终截图显示 OKX 公共 BTC/USDT 行情、96 根 5 分钟数据、行情请求耗时和数据年龄 | 概念稿示例数字被真实公共数据替代 |
| 订单检查器 | 买卖切换、限价输入、启用前禁用 | 未配置凭证时预检和启用按钮保持禁用；空数量的预计金额显示 `—` | 保留交互层级，删除容易被误认成真实委托的示例数量 |
| 确定性风控 | 右栏清楚列出规则和急停 | 只展示已实现规则：单笔金额、行情新鲜度、限价偏离、挂单数、SPOT/cash | 移除了未实现的日/周亏损与总敞口宣称 |
| 账户、订单与审计 | 下方挂单和审计轨道 | 无凭证时显示诚实空态；审计链在加载/失败时显示待检查，不沿用旧数据 | 不复制概念稿中的模拟挂单和虚构收益 |
| 移动端 | 单列内容、固定底部导航、急停可达 | 375×812 验收得到 6 个导航项，设置可进入，`scrollWidth = clientWidth = 360` | 无页面级横向溢出；设置不再被移动导航遗漏 |
| 键盘与弱动效 | 焦点清楚、支持减少动效 | 急停对话框初始焦点位于弹窗内，Tab 圈定，Escape 可关闭；保留 `prefers-reduced-motion` | 补齐弹窗焦点恢复与键盘关闭 |

有意差异：概念稿是视觉方向，其中的价格、挂单、收益和“全部通过”均为构图示例；最终实现只显示运行时 OKX 公共数据、本地审计事件或明确空状态。
