# 墨衡 MOHENG 视觉与交互系统

墨衡定位为“机构级 AI 量化研究与治理驾驶舱”。专业性来自真实证据密度、清晰的信息层级和一致的风险语义，不来自赌场化霓虹、金币、机器人头像或虚构 AI 置信度。

视觉目标以 [专业驾驶舱概念稿](moheng-concept.png) 为基准；实际界面只显示后端真实数据，概念稿中的示意数字不会进入产品。

## 品牌

- 中文名：**墨衡**。墨代表沉静、记录与可追溯；衡代表收益、风险、证据和权限之间的校准。
- 英文：**MOHENG**，只作国际化识别，不翻译成收益承诺。
- 标识：现代浑仪/天圆地方与精密衡轴。真实 PNG 和 Windows ICO 位于 `assets/brand/`；前端使用 `frontend/src/assets/moheng-app-icon.png`。
- 兼容标识：`Tideguard` 数据目录、Credential Manager service、mutex、AppId 和内部 EXE 名称保持不变，避免升级丢失账户绑定或形成双安装。

## 色彩语义

| 语义 | 色彩 | 用途 |
|---|---|---|
| 墨黑 / 深靛 | `#050B11` / `#071018` | 全局背景、稳定运行基底 |
| 玉青 | `#7ED6C4` | 已验证、健康、主操作 |
| 冷蓝 | `#4B9DE8` | 计算、训练、OOS、信息 |
| 青铜 | `#B89052` | 监督、治理、证据与等待 |
| 朱砂 | `#D75B51` | Live 真实资金、急停、不可逆风险 |
| 主文字 | `#E7EFEC` | 标题和核心数字 |
| 次文字 | `#9AAEB2` | 辅助解释和时间 |

涨跌、系统健康、操作和危险不能复用同一颜色。Live 必须同时使用“LIVE / 真实资金”文字、朱砂色、窗口上下文和确认短语，不能只靠颜色表达。

## 排版与密度

- 字体：`Inter, PingFang SC, Microsoft YaHei UI, system-ui`；哈希和精确数值使用等宽栈。
- 正文不低于 13–14px，辅助信息不低于 12px，关键数字 24–36px。
- 8px 基准间距；表格保持高密度但不压缩可读性。
- 关键按钮和移动触控目标至少 44px。
- 使用细边框、克制阴影和 5–14px 圆角；不使用玻璃拟态堆叠和无意义发光。

## 信息架构

1. **运行中心**：NOW / WHY / NEXT、模型净值与基准、回撤、模型自有仓位、问题中心、AI 流水线。
2. **数据谱系**：官方来源、覆盖起止、回填状态、缺口/冲突、快照哈希和 rolling split。
3. **训练任务**：阶段、进度、数据行、候选配置、资源遥测和降级规则。
4. **模型评估**：champion、同 cohort 候选比较、walk-forward 矩阵、Shadow、谱系和证据抽屉。
5. **策略执行**：模型自有持仓、订单/成交/费用/退出、人工诊断工具和急停。
6. **审计与设置**：持久问题中心、事件链、凭证入口、Demo/Live 切换、版本和安全边界。

全局只有一个当前环境、一个安全状态和一个急停。旧的 10 分钟人工演练不再与长期 Demo master 混在首页。

## 解释层

产品面向专业使用，但不要求用户先学会所有术语：

- 默认“结论”层先回答现在、为什么和下一步；
- “证据”层展开模型 ID、SHA-256、cohort、split protocol、fold 和订单状态；
- 图表必须有直接标签、文本替代和空状态；
- 无遥测时显示“未上报/等待”，禁止用 10,000、62% 或示例曲线冒充真实值；
- 不同 cohort 的报告不可直接排行，界面必须明确说明口径不同。

## 动效

- 动效只表达数据同步、训练阶段、状态切换和抽屉层级。
- 默认 140–240ms；长任务使用真实阶段变化而非无限“AI 思考”动画。
- 支持 `prefers-reduced-motion`；关闭动效不影响任何信息。

## 响应式与可访问性

- `> 1220px`：完整侧栏和多列研究驾驶舱。
- `721–1220px`：压缩导航，主图和证据面板重排。
- `≤ 720px`：单列、底部或紧凑导航、表格可横向查看；急停和 LIVE 标识保持可见。
- 状态同时使用图标、文字和颜色；所有核心操作可键盘完成并有清晰焦点。
- 图表提供 `role=img` 与真实摘要；哈希长文本允许安全换行或复制。
