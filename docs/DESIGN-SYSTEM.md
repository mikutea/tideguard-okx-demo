# Tideguard 视觉系统

视觉方向来自完整桌面概念稿，定位为“机构级风险控制台”，避免赌场化的霓虹、金币、收益庆祝和虚构 AI 置信度。

## 设计令牌

- 主背景：`#0B0E12`
- 一级表面：`#10151B`
- 二级表面：`#151C23`
- 边框：`#27313A`
- 主文字：`#EDF3F6`
- 次文字：`#A4B0B9`
- 健康/安全：`#22C6A2`
- 警告：`#E8B45D`
- 危险/急停：`#F05D66`
- 圆角：`7 / 11 / 13px`
- 间距：以 `8px` 为基准
- 字体：`Inter, PingFang SC, Microsoft YaHei, system-ui`
- 数字：tabular numerals

## 首屏锁定内容

- 持续可见的“OKX 模拟盘”和当前安全状态。
- 连接健康、行情数据年龄、本机凭证状态。
- BTC/USDT 公共行情与来源。
- 模拟下单、限时演练授权、确定性风控、急停。
- 模拟账户挂单与本地审计哈希链。

实际实现不复制概念稿中的示例数字。没有 OKX 数据时显示明确空状态。

## 响应式

- `> 1220px`：完整左侧导航、主行情、右侧检查器。
- `721–1220px`：图标导航；检查器在行情下方分栏。
- `≤ 720px`：单列内容、底部导航、粘性安全顶栏；表格变为订单卡片。

## 可访问性

- 状态同时使用图标、文字和颜色。
- 所有关键操作有可见键盘焦点。
- 图表提供文本替代说明。
- 移动触控目标不小于约 40px；主操作为 44px 等级。
- 支持 `prefers-reduced-motion`。
